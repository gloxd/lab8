# Задание 1

## Задача 1

### Текст задачи

Разработать консольное приложение с дружественным интерфейсом с возможностью выбора заданий для работы с «базой данных (БД)», хранящейся в бинарном файле. Вариант №6 — «Журнал класса».

Перечень полей (минимум 5):
- `Id` (int) — уникальный идентификатор записи (ключ);
- `FullName` (string) — ФИО учащегося;
- `Subject` (string) — наименование предмета;
- `Grade` (int) — оценка;
- `IsPresent` (bool) — отметка о присутствии на занятии.

Функции приложения:
1. Чтение базы данных из бинарного файла.
2. Просмотр базы данных.
3. Удаление элементов по ключу.
4. Добавление элементов.
5. Реализация 4 LINQ-запросов (2 возвращают список, 2 — одно значение).

### Алгоритм решения

1. **Проектирование сущности:**
   - Объявление 5 автосвойств с разным типом данных (`int`, `string`, `bool`).
   - Реализация конструктора по умолчанию и конструктора с параметрами.
   - Перегрузка метода `ToString()` для форматированного вывода записи в консоль.

2. **Вспомогательный класс:**
   - **Сохранение/Чтение:** Использование `BinaryWriter` и `BinaryReader` для сериализации/десериализации списка объектов `StudentProgress` в файл `.dat`.
   - **Добавление:** Считывание текущих записей, генерация нового `Id` с помощью LINQ (`records.Max(r => r.Id) + 1`), запись нового элемента и перезапись файла.
   - **Удаление:** Поиск записи по `Id` с помощью `FirstOrDefault(r => r.Id == id)`, удаление из коллекций и обновление бинарного файла.
   - **LINQ-запросы:**
     - Запрос 1 (Список): Фильтрация отличников (`Grade == 5`), присутствовавших на занятии (`IsPresent == true`) через query-синтаксис LINQ.
     - Запрос 2 (Список): Фильтрация учеников по предмету без учета регистра и сортировка по имени (`Where`, `OrderBy`).
     - Запрос 3 (Одно значение): Расчет среднего балла класса по всем предметам с помощью метода `.Average(r => r.Grade)`.
     - Запрос 4 (Одно значение): Подсчет общего количества пропусков с помощью метода `.Count(r => !r.IsPresent)`.

3. **Интерфейс и обработка ошибок:**
   - Консольное меню с циклом `while` и оператором `switch`.
   - Защищенный ввод чисел и логических значений с использованием `int.TryParse` и валидацией диапазонов для предотвращения падения программы при некорректном вводе.
   - Использование блоков `try-catch` при операциях ввода-вывода файлов.
